07设计取舍

为什么逐字绘制

  • 换成 gb2312 字体库后字宽会变
  • 按实测字宽排版，不会错位
  • 字间距可控，数字不粘连

为什么不整屏重画

  • 单缓冲，清屏期间整屏是黑的
  • 分区比较 + 局部清除
  • 画面稳定，不闪烁

为什么回退要降频

  • 目标不可达时 connect 会长时间阻塞
  • 阻塞会拖垮时钟刷新
  • 改成 5 s 探测 + 250 ms 超时

为什么解析不写死字段

  • AIDA64 项目顺序可自定义
  • 按「使用率 / 温度 / 上传」等关键词匹配
  • 换配置不用改固件
