## 三、模式状态机（含 PC 回退）

```
                 网页 POST /api/config  (mode)
       ┌───────────────────┬────────────────────┐
       ▼                   ▼                    ▼
 ┌──────────┐        ┌──────────┐        ┌──────────┐
 │ mode = 0 │        │ mode = 1 │        │ mode = 2 │
 │   时钟    │        │  空气质量 │        │  电脑状态 │
 └──────────┘        └──────────┘        └────┬─────┘
                                              │
                              15 秒没拿到数据  │  数据恢复
                        ┌─────────────────────┴──────────────────┐
                        ▼                                        │
                 ┌──────────────┐                                  │
                 │ 回退显示时钟   │──────────────────────────────────┘
                 │ (仍在 mode 2) │  探测间隔 5s，超时 250ms
                 └──────────────┘
```

要点：回退只改变**画什么**，不改变 `cfg.mode`。所以网页上仍然显示"电脑状态"，数据一回来自动切回去，用户不需要手动操作。

## 四、分层说明

| 层 | 函数 | 职责 |
|---|---|---|
| 驱动层 | `MatrixPanel_I2S_DMA` + `VirtualMatrixPanel` | HUB75 时序、1/32 扫描、`setRotate(true)` 横屏 |
| 绘图原语 | `drawTextGap` `drawTextLeft` `textW` `charWidth` `drawTempStr` | 逐字绘制、1px 字间距、按区域居中或左对齐、手绘度数圈 |
| 渲染层 | `clockRender` `airUpdate` `pcUpdate` | 分区比较，只重绘变化区域 |
| 解析层 | `jsonFloat` `pcFeed` `parsePcPayload` | 从 JSON / SSE / HTML 里按关键词取值 |
| 采集层 | `fetchAir` `fetchPc` | HTTP 拉取，带超时与重试 |
| 配置层 | `loadConfig` `saveConfig` | LittleFS 读写 `config.json` |
| 服务层 | `setupWeb` `serveIndex` | 配置网页 + REST 接口 |

## 五、刷新策略（关键：避免整屏闪烁）

| 画面 | 区域 | 重绘条件 | 清除范围 |
|---|---|---|---|
| 时钟 | 日期 + 星期 | 跨天 | 16px 条 |
| | 时间 HH:MM | 分钟变化 | 48px 条 |
| | 秒 + 进度条 | 每秒 | 16px + 增量条 |
| 空气 | `PM2.5` 标题 | 切模式 | 16px |
| | PM2.5 数值 | 值变化 | 48px |
| | CO2 行 | CO2 变化 | 16px |
| | 温湿度行 | 温湿度变化 | 16px |
| 电脑 | 6 行独立 | 各行文本变化 | 各 16px |

原则：**任何情况下都不整屏清空**，只有切模式 / 回退切换时才 `fillScreen(0)` 一次。

## 六、时间参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `cfg.airRefresh` | 10s | 空气质量采集间隔 |
| `cfg.pcRefresh` | 1s | 电脑状态采集间隔 |
| `PC_STALE_MS` | 15s | 多久没数据算掉线（也是回退阈值） |
| `PC_RETRY_MS` | 5s | 回退期间的探测间隔 |
| 快速探测超时 | 250ms | 连接 + 读取 |
| 正常抓取超时 | 1500 / 800ms | 连接 / 读取 |
